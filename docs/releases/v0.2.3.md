# Yumi Desktop 0.2.3

Стеклянный фон готовится вне потока интерфейса и используется всеми панелями. Прокрутка больших
списков больше не пересчитывает фон и размытие для каждой карточки. Результаты проверки задержки
сохраняются пакетами; анимации засыпают в трее и при свёрнутом окне. Палитры, формы и эффекты сохранены.

В настройках появился переключатель подключения VPN после запуска — к выбранному серверу,
после готовности службы. По умолчанию он выключен.

Там же — обновления приложения: проверка новых выпусков, фоновая загрузка с прогрессом и отменой,
проверка файла и перезапуск для установки. В установленной версии готовое обновление можно
также поставить при выходе. Автоматический режим отключается отдельно.
