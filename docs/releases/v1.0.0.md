# Yumi Desktop 1.0.0

Выпуск, на котором Yumi перестаёт быть программой для одной системы: тот же клиент, та же служба
и тот же набор возможностей теперь работают на Windows, Linux и macOS.

- **Linux и macOS полностью.** Туннель на собственном адаптере ядра Xray, kill switch (nftables на
  Linux, pf на macOS), горячее переключение серверов, сплит-туннелирование по приложениям с
  удобным выбором, гео-базы «русские сайты напрямую», подписки и передача по QR, выбор адаптера,
  автозапуск, автообновления. Служба ставится при первом подключении одним запросом пароля и
  живёт в systemd или launchd; приложению она отвечает по unix-сокету тем же протоколом, что и
  по именованному каналу на Windows.
- **Местоположение — как у сервера.** Пока туннель подключён, системная таймзона переезжает на
  серверную, а системные источники геолокации замолкают: сайты и приложения, спрашивающие, где
  машина, слышат страну сервера. На отключении всё возвращается; состояние машины записывается на
  диск до первого изменения, поэтому возвращается оно даже после падения службы. Опция выключена
  по умолчанию — системные часы действительно сдвинутся.
- **Подписка больше не двигает выбранный сервер.** Обновление, из которого провайдер убрал
  выбранный сервер — или вовсе ответил пустым списком, — оставляет его строку на месте и выбор
  при нём: экран говорит правду о том, куда идёт трафик, а не «сервер не выбран» над живым
  туннелем. Строка уходит только после того, как выбран другой сервер. Ротация адреса по-прежнему
  отслеживается по имени.
- Трей и меню-windows-варианты без изменений; на Linux иконка в трее требует совместимой с
  AppIndicator оболочки — там, где её нет, приложение честно сообщает и закрывается по крестику.

Служба на Linux разрешает в kill switch свой собственный аккаунт (root), как и требует модель
nftables: под свободой остаются системные процессы, но не пользовательский трафик. Разрешение DNS
через туннель включается на время подключения и снимается на выходе. macOS-сборка собрана под
Apple Silicon и не подписана — при первом запуске правый клик → «Открыть».

Автоматические проверки покрывают всё, что можно проверить без реальной сети: матрицу запросов
приложения против закреплённого ядра, горячую замену outbound, привилегии протокола, гео-загрузку,
гонки воркера, интерфейсные тесты — на Windows; параллельно CI собирает Linux и macOS: те же JVM
тесты под Xvfb, тесты службы под целевой ОС и пакеты .deb/.rpm/.dmg/.pkg. Ручные сценарии для
трёх систем описаны в MANUAL-TESTS.md.
