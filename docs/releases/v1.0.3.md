# Yumi Desktop 1.0.3

- DNS-защита Windows включается с первого подключения, независимо от kill switch.
- Сетевые настройки применяются сразу, включая изменения во время подключения.
- Смена сервера переподключает VPN-потоки и сохраняет прямые соединения исключённых приложений.
- Проверена передача данных через поддерживаемые транспорты.
