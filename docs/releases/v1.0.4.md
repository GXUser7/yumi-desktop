# Yumi Desktop 1.0.4

- Сцена живого фона и размытие перенесены на GPU с адаптивным ограничением частоты кадров — нагрузка на процессор при открытом окне снижена в 3,5–9 раз.
- Усилена защита kill switch и фильтрация утечек DNS, DoT, LLMNR и IPv6 в службах Windows (WFP), Linux (nftables) и macOS (PF).
- Усилена проверка прав IPC, целостности SHA-256 при автообновлении и безопасная переустановка службы в установщике.
- Улучшены разбор подписок и deep link-ссылок, переподключение при смене настроек и добавлена документация на русском языке.
